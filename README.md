The Mansion is Haunted. You have to save it.
Shoot and stab zombies in this top-down shooter to clear levels, unlock more powerful weapons, and find the hidden treasure deep in the mansion.

Features
- 4 zombie filled levels
- 4 weapons: knife and pistol (default), shotgun and machine gun (unlockable)
- epic bossfight
- endless mode for highscore
- original graphics and soundtrack
- progress saving
